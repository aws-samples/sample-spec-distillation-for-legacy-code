# Synthetic corpus: JC Change Orders (construction contractor)

A small, made-up legacy Job Cost module that manages change orders for construction jobs: owner change
orders that revise the contract, subcontract change orders that revise a subcontract's committed cost,
and internal change orders. It covers entry, approval, posting, subcontract maintenance, a change order
log report, and a sync with an external field app. The stack is VB.NET WinForms, SQL Server tables,
stored procedures and triggers, and a Crystal Reports definition stand-in. Every name, table, user and
comment is invented, and the code is not meant to compile or run.
